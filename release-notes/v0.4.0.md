# 0.4.0

- Keep the existing themed Omarchy panel and normal plugin lifecycle.
- Build pinned AWCC thermal and AlienFan/AlienFX sources without their GUI,
  shell executor, socket daemon, hotkey binder, or floating GUI dependencies.
- Use discovered kernel capabilities first; limit legacy ACPI to exact known
  models and already-loaded drivers. Retain backend-specific boost semantics.
- Discover devices without brightness/reset/save writes. Require verified
  lighting maps rather than applying x15 R2 indices to other devices.
- Route lighting through Polkit/D-Bus, with bounded native child processes.
- Display extra fans and unavailable telemetry honestly. Gate additive curves.
- Build the committed fork checkout, not upstream's previous prebuilt release.
- Remove the old device-permission udev rule from packaging. Track fan ownership
  for cleanup; refuse competing services instead of stopping them.
- Update Go dependencies. See docs/awcc.md for audit and verification scope.
